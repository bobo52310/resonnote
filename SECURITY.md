# Security Policy

If you believe you have found a security vulnerability in ResonNote, please report it privately through GitHub:

**Security → Report a vulnerability** on <https://github.com/bobo52310/resonnote>.

Please do not open a public issue for security problems. Include what you found, the steps to reproduce it, and the affected platform and Chrome version. This is a personal open-source project maintained on a best-effort basis, so there is no guaranteed response time, but reports are read and taken seriously.

Only the latest `main` branch is supported.
