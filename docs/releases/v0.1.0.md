## ResonNote 共鳴筆記 v0.1.0

第一個公開版本：看劇有共鳴的那一秒，一鍵記下畫面、秒數、台詞與心得的 Chrome 擴充功能。

### 主要功能

- 按快捷鍵 `⌥⇧N`（可在 `chrome://extensions/shortcuts` 改），或點播放頁上浮出的「記下這一刻」按鈕：先截圖、再暫停影片，跳出小視窗讓你補心得。`Enter` 存檔，`Esc` 取消。
- 筆記本依「平台＋片子」分組，點時間按鈕跳回那一刻。
- 匯出：LINE 用的圖卡（PNG）、單一 HTML 網頁檔、Markdown 加圖片的 zip。
- 「全部備份」與「從備份還原」，備份是一個 zip。

### 支援平台

Netflix、YouTube、Disney+。目前只在 macOS 的 Chrome 上實測過，其他系統與瀏覽器沒測。

### 安裝步驟

1. 下載下方的 `resonnote-0.1.0-chrome.zip`，解壓縮到一個之後不會刪掉的資料夾（Chrome 會直接從這個資料夾載入擴充功能）。
2. 在 Chrome 開 `chrome://extensions`，右上角打開「開發人員模式」。
3. 按「載入未封裝項目」，選剛剛解壓縮的資料夾。
4. 已經開著的 Netflix、YouTube、Disney+ 分頁各重新整理一次，擴充功能才會生效。

**之後更新：** 下載新版 zip，用新版內容取代資料夾裡的檔案，再到 `chrome://extensions` 按 ResonNote 的重新載入。這個版本的擴充功能 ID 是固定的，筆記會保留。

### 隱私

筆記和截圖只存在你瀏覽器本機的 IndexedDB，不會上傳，沒有帳號，也沒有任何追蹤。

### 已知限制

- 這是依賴各平台頁面內部結構的做法，網站改版就可能壞。各平台的退路與限制見 [README 的「已知限制」](https://github.com/bobo52310/resonnote#已知限制)。
- 移除擴充功能會連筆記和圖片一起刪掉，請定期按「全部備份」。
