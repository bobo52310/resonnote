## ResonNote 共鳴筆記 v0.1.1

修正版，建議從 v0.1.0 更新。功能和畫面都沒有變，筆記會完整保留。

### 修正

- 資料庫升級改成依版本分段進行：之後的版本要調整資料格式時，只會補做還沒做過的步驟，不會因為重複建立資料表而讓存檔全部失敗（[#1](https://github.com/bobo52310/resonnote/issues/1)）。
- 從這版開始，之後的新版要升級資料庫時，還開著的這版筆記本分頁會主動讓開，升級不會被卡住（v0.1.0 沒有這個機制）。這一項要先裝在你的瀏覽器裡，之後的升級才用得到，所以建議現在就更新。

這個版本本身沒有改資料格式，資料庫還是第 1 版。

### 安裝步驟

1. 下載下方的 `resonnote-0.1.1-chrome.zip`，解壓縮到一個之後不會刪掉的資料夾（Chrome 會直接從這個資料夾載入擴充功能）。
2. 在 Chrome 開 `chrome://extensions`，右上角打開「開發人員模式」。
3. 按「載入未封裝項目」，選剛剛解壓縮的資料夾。
4. 已經開著的 Netflix、YouTube、Disney+ 分頁各重新整理一次，擴充功能才會生效。

**從 v0.1.0 更新：** 用新版 zip 的內容取代原本資料夾裡的檔案，再到 `chrome://extensions` 按 ResonNote 的重新載入。擴充功能 ID 不變，筆記會保留。
